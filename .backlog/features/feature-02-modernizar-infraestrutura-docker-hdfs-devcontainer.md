## Contexto / Problema

Rascunho: a infraestrutura Docker precisava de uma organização mais consistente
para executar Spark e HDFS, além de ajustes no ambiente DevContainer.

## Objetivo

Rascunho: modernizar a composição dos serviços, centralizar configurações HDFS
e melhorar a integração do DevContainer com o ambiente de desenvolvimento.

## Critérios de aceite

Rascunho — revisar e complementar manualmente.
