## Contexto / Problema

Rascunho: a configuração do Dev Container e dos serviços Docker contém scripts
legados e estruturas divergentes, dificultando a manutenção do ambiente.

## Objetivo

Rascunho: consolidar a configuração Docker, atualizar o Dev Container e
padronizar as tarefas e dependências utilizadas no desenvolvimento.

## Critérios de aceite

Rascunho: revisar manualmente após a validação do diff e dos serviços Docker.
