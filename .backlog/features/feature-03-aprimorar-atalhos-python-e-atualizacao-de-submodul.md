## Contexto / Problema

Rascunho: o ambiente precisa de um atalho conveniente para executar Python e de
uma rotina reutilizável para sincronizar os submodules no VS Code.

## Objetivo

Rascunho: centralizar a atualização dos submodules em um arquivo executável e
disponibilizar o alias `py` no container.

## Critérios de aceite

Rascunho: revisar e complementar manualmente.
