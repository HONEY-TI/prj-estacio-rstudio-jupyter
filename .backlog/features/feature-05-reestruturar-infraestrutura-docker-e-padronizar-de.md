## Contexto / Problema

Rascunho: a infraestrutura Docker e os arquivos de configuração do Dev Container
estão distribuídos entre estruturas legadas, dificultando a inicialização e a
manutenção do ambiente de desenvolvimento.

## Objetivo

Rascunho: consolidar a configuração do ambiente pai, atualizar os serviços e
automatizar a inicialização do Dev Container com suporte aos componentes atuais.

## Critérios de aceite

Rascunho: revisar manualmente após a validação do diff e dos serviços Docker.
